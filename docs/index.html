A bounded convergence loop

Open-ended self-QA spends the budget without converging. This loop has a measurable stop condition, an iteration ceiling, and an honest report when thresholds are unmet.

Inspectstack, project memory, before-state
Directsurface, dials, direction contract
Buildreal content, tokens, all states
Render375 / 768 / 1440
Auditdetector + fresh-context reviewers
Gatescore, caps, delta vs previous
Reportblockers first, then the /100

Thresholds unmet sends the top severity tier back through Render, at most four times. Each closed cycle appends a trajectory note to project memory, so the next session starts from the path taken, including what to fix first.

76 rules, zero dependencies

Regex tripwires over files and project structure: fast, deterministic, and honest about their limits. A flag is a signal. Every finding gets a verdict before it is acted on, and deliberate deviations are waived inline, next to the code.

content/17

Fabricated metrics, assistant chatter, model-disclaimer leaks, dead metaphors, puffery, stock faces on testimonials, unlabeled simulations.

system/15

Off-token colors, theme-toggle desync, near-duplicate tokens, container-width drift, primitives bypassed by app code.

a11y/11

Zoom disabled, clickable divs, focus outline removed with no replacement, legal content behind a reveal wrapper.

slop/11

Purple-blue gradients, negative parallelism, reframe headings, template section order, the same fade-up on every section.

motion/10

Layout-property transitions, entrances from scale zero, counters resting at zero, a missing reduced-motion guard.

i18n/7

Providers without an explicit locale, formatters on the browser default, leaf/parent key collisions, partial catalogs.

Plus five more across correctness/, ux/, layout/, perf/ and project scope. Run it on anything: node scripts/lexia-design-audit.mjs --deep src

When two principles collide, the lower number wins

The order is fixed and the arbitration is recorded, so taste never quietly outranks evidence.

  1. user's objective
  2. clarity and usability
  3. accessibility
  4. content truthfulness
  5. system coherence
  6. performance
  7. visual identity
  8. distinction
  9. motion
  10. implementation convenience

An explicit brief outranks the plugin's taste. It never outranks usability evidence, accessibility, content truth or arithmetic.

Install

Clone, verify, install. Node 18+ on PATH; hooks are advisory and never block.

From your shell

# clone and verify
git clone https://github.com/lexsantor/lexia-design
claude plugin validate ./lexia-design

# or try it without installing
claude --plugin-dir ./lexia-design

Inside a Claude Code session

/plugin marketplace add lexsantor/lexia-design
/plugin install lexia-design@lexia

# then
/lexia-design  build a pricing page for <product>
/lexia-design:design-audit  src/
